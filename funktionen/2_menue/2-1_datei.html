Menü: Datei

Das Datei-Menü dient zum Eröffnen, Laden und Speichern von Wahlvorgängen.

BefehlBeschreibungTaste
Neue WahlEröffnet einen neuen Wahlvorgang
ÖffnenLaden Sie einen vorhandenen Wahlvorgang
Importiere WahlErzeugt ein neuen Wahlvorgang aus einem Import (XLSX,WHL) (→ Wahlgang anlegen)
Öffne vorherigeÖffnet den bzw. einen der vorherigen Wahlvorgänge
Arbeitsverzeichnis
öffnen		Öffnet das Arbeitsverzeichnis im Datei-Explorer
SpeichernSpeichere Wahlvorgang unter dem bisherigen Namen
Speichere unter...Speichere Wahlvorgang unter einem neuen Namen
Importiere StimmenAn mehreren Rechnern oder maschinell ausgezählte Stimmen werden eingelesen (→ Stimmenimport).
Exportiere StimmenWenn die Auszählung auf mehreren Rechnern durchgeführt wird, können Zwischenergebnisse auf Datei ausgelagert und auf dem zentralen Rechner importiert werden (→ Stimmenexport).
Gremium importierenEin vollständiges Gremium wird aus einem anderen Wahlvorgang importiert (Kandidat:inneneingabe an verschiedenen Rechnern (→ Verarbeitung an mehreren Arbeitsplätzen)
BeendenBeendet die Bearbeitung. Wurde der Wahlvorgang nach Änderungen noch nicht gespeichert, wird dieses angemahnt.
