---
title: "Eine neue Lizenz installieren"
---

uniWAHL kann zu Test- und Evaluierungszwecken an jedem PC installiert werden. Ohne Lizenzdatei wird uniWAHL als Demoversion (kein Speichern möglich) installiert.

Supportvertragskunden erhalten regelmäßig aktuelle Programmversionen und die dazu passende Lizenzdatei (i.d.R. als institutionsweite Lizenz). 30 Tage vor Ablauf einer Lizenzdatei informiert Sie uniWAHL per Dialog beim Start der Anwendung automatisch. Die Lizenz enthält auch das Paket uniSCAN, insofern dieses bestellt wurde.

1. Kopieren Sie die Lizenz-Datei auf Ihren Datenträger.
1. Starten Sie **uniWAHL**.
1. Wählen Sie den Menü-Befehl `Hilfe / Lizenz` und betätigen Sie `Ändern`. (Beim ersten Start werden Sie nach der Lizenzdatei gefragt.)
1. Geben Sie den Pfad zur Datei „xxx.lic“ an und `Öffnen` Sie diese. Die Lizenz wird in Ihr System eingebunden.
1. Verwahren Sie die Datei an einem sicheren Ort.
