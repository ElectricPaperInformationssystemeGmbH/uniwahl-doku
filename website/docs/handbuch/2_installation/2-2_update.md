---
title: "Update-Prüfung"
---

uniWAHL führt beim ersten Start der Anwendung pro Tag eine automatische Update-Prüfung durch. Voraussetzung ist eine aktive Verbindung zum Server von Electric Paper. Liegt eine neuere Version vor, wird diese mit Update- und Installationshinweisen zum Download angeboten. Unter `Hilfe` und `Update suchen` lässt sich die Prüfung jederzeit manuell anstoßen. Automatische Updates können allerdings nicht deaktiviert werden.

:::tip

**Tipp:** Halten Sie uniWAHL auf allen Arbeitsplätzen stets auf dem neuesten Stand.

:::
