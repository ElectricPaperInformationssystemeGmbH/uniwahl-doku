---
title: "Update-Prüfung"
---

uniWAHL führt beim ersten Start der Anwendung pro Tag eine automatische Update-Prüfung durch. Voraussetzung ist eine aktive Verbindung zum Server von Electric Paper.

Bei dieser Prüfung wird nur ein Patch der installierten Version angeboten (z. B. 7.1.0 → 7.1.1). Es erscheint ein Dialog mit den Knöpfen „Jetzt Aktualisieren“, „Release Notes“, „Abbrechen“ und „Hilfe“. Nach „Jetzt Aktualisieren“ wird uniWAHL beim nächsten Start aktualisiert. Schlägt die Prüfung beim Start fehl (z. B. ohne Verbindung zum Server), erscheint keine Meldung.

Über `Hilfe / Updates suchen` lässt sich die Prüfung jederzeit manuell anstoßen. Nur dabei wird auch eine neue Haupt- oder Unterversion (z. B. 7.2) gemeldet, mit einem Link zum Download.

Die automatische Update-Prüfung lässt sich nicht abschalten; installiert wird nur nach Ihrer Bestätigung.

:::tip

**Tipp:** Halten Sie uniWAHL auf allen Arbeitsplätzen stets auf dem neuesten Stand.

:::
