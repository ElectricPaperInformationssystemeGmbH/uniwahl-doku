Es folgt eine ausführliche Darstellung aller Tätigkeiten, die während des Wahlverfahrens ausgeführt werden, in diesem Kapitel die Vorbereitung der Wahl.

- **Vorbereitung der Wahl**: Eine neue Wahl steht an. Also müssen die Vorbereitungen getroffen werden.
- **Wahl konfigurieren**: Die Wahlordnung muss ggf. eingearbeitet werden. Für welche Organe und Gruppen wird gewählt?
- **Wahlausschreibung**: Die Wahlausschreibung wird vorbereitet und herausgegeben.
