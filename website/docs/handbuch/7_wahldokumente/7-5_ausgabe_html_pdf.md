## HTML {#html}

Die Sprache des World-Wide-Web ist *HTML* (*Hypertext Markup Language*). Wenn Sie dieses Ausgabeformat wählen, können Sie die Ausgaben mit geeigneten Internet-Browsern (Mozilla Firefox, *Internet Explorer/Microsoft Edge*) ausgeben. Dabei haben Sie folgende Möglichkeiten:

- Sie können die Bekanntmachung des Wahlergebnisses direkt in Ihr Hochschul- oder Firmennetz stellen und den Wahlberechtigten auf zeitgemäße Weise sehr schnell bekannt machen. Auch für die Wahlbekanntmachung hat sich dieses Verfahren bewährt.
- Sollte Ihnen das automatisch erzeugte Bild der Ausgabe nicht zusagen, können HTML- erfahrene (z.B. studentische) Mitarbeiter:innen sehr schnell Modifikationen vornehmen (im MS-Internet Explorer/Edge z.B. über Menü: *Ansicht / Quelltext*).
- Die Dateien im *HTML*-Format haben die Erweiterung „.*html*“ oder *„.htm“*. Wenn Sie diese im Windows-Explorer doppelt anklicken, öffnet sich Ihr Browser automatisch mit dieser Datei.

## PDF {#pdf}

Ein weiteres gängiges Format ist PDF (*Portable Document Format*). PDF-Dateien werden z.B. mit dem Adobe Acrobat Reader gelesen.

Tipp: Sie sollten vor Beginn des Wahlverfahrens vom Hauptwahlausschuss diese Art der Publikation genehmigen lassen. Sie könnten dann alle Wahlberechtigten per E-Mail auf die Wahl aufmerksam machen und auf die entsprechende Web-Seite hinweisen.

## So erzeugen Sie HTML / PDF-Dokumente {#so-erzeugen-sie-html-pdf-dokumente}

- Erstellen Sie das Dokument wie gewohnt mittels * bzw. * und geben Sie es in dem gewünschten Format aus:
- **PDF**: Menü: Datei / Exportieren als PDF...
- **HTML**: Menü: Datei / Speichern unter... Wählen Sie als Dateityp: HTML-Dokument.
