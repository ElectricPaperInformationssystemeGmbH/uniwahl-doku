---
title: "Menü: Funktionen"
---

Das Funktionen-Menü startet einige wichtige Funktionen im Wahlvorgang.

| **Befehl** | **Beschreibung** |
|---|---|
| Kandidat:in suchen | Im Wahlvorgang werden Kandidat:innen nach Namen gesucht: Wo kandidiert Frau Meier? (→ [Kandidat:innen suchen](../../handbuch/8_funktionen/8-2_kandidat_in_suchen.md)) |
| Wahlberechtigte zählen | Mit dieser Funktion können die Wahlberechtigten der Wahlbereiche gezählt werden (→ [Wahlberechtigte zählen](../../handbuch/6_auszaehlung_ergebnis/6-6_wahlberechtigte_zaehlen.md)). |
| Wahlberechtigte zählen (alle Bereiche) | Ermittelt die Zahl der Wahlberechtigten für alle Wahlbereiche anhand der Wählergruppe im Wahlverzeichnis. |
| Alle Kandidaten entfernen | Alle Kandidat:innen werden gelöscht. Die gesamte Struktur bleibt erhalten: Wahlordnung, Texte, Layout, Gremien und Wahlbereiche. |
| Anonymisieren der Wahl | Alle Namen werden durch „Kandi_xx“ und die Vornamen durch „Liste_yy“ bzw. „Einzel“ ersetzt. |
| Status zurücksetzen | Im Notfall können Sie hier den Status des Wahlbereichs zurücksetzen, wenn Sie anders nicht korrigieren können. Ggf. ist die Genehmigung der Wahlleitung einzuholen (→ [Status zurücksetzen](../../handbuch/8_funktionen/8-1_status_zuruecksetzen.md)). |
| Status auf 3 zurücksetzen (Alle Bereiche) | Mit dieser Funktion lassen sich alle Wahlbereiche auf den Status "Kandidat:inneneingabe fertig" (dunkelblau) zurücksetzen, um z.B. Importe (uniSCAN, OWS) besser testen zu können. |
| Wahlkennung bearbeiten | Die Wahlkennung ist wichtig beim Import extern – durch Scannen oder online - gezählter Stimmen. |
| Listenreihenfolge losen | Die Reihenfolge der Listen auf den Wahldokumenten kann gelost werden. |
| Auswerteprotokoll | zeigt die Vorgehensweise bei der Zuweisung der Sitze an. Hier wird auch ein Vergleich d’Hondt / Hare-Niemeyer / Sainte-Laguë für die aktuelle Gruppe gezeigt. (→ [Auswerteprotokoll](../../handbuch/6_auszaehlung_ergebnis/6-5_auswerten.md)) |
| Nachrück-Reihenfolge | zeigt die listenübergreifende Nachrück-Reihenfolge für die aktuelle Gruppe an. (→ [Nachrückreihenfolge](../../handbuch/6_auszaehlung_ergebnis/6-5_auswerten.md#reihenfolge-bei-listenuebergreifendem-nachruecken)) |
| Kandidat:innen alphabetisch sortieren | Die Einzelkandidat:innen werden alphabetisch sortiert. |
| Einzelkandidat:innen gelost sortieren | Die Reihenfolge der Einzelkandidat:innen wird gelost. |
| Sitzverteilung-Rechner | Ruft den Sitzverteilungsrechner auf (→ [Sitzverteilung-Rechner](../../handbuch/8_funktionen/8-8_sitzverteilungsrechner.md)). |
| Sicherungskopie | Erlaubt das Laden und Löschen von Sicherungskopien (→ [Sicherungskopie](../../handbuch/8_funktionen/8-9_sicherungskopien.md)). |
| Logbuch öffnen ... | Das Logbuch zeigt, wer wann was geändert hat. Es wird im Browser geöffnet. (→ [Logbuch](../../handbuch/8_funktionen/8-11_logbuch.md)) |
| Mehrfachzugriff<br />verhindern | Bei Zugriff der Wahldatei durch mehrere Personen kann nur eine Änderungen durchführen. (→ [Mehrfachzugriff verhindern](../../handbuch/8_funktionen/8-10_mehrfachzugriff_verhindern.md)) |
| Unverschlüsselte<br />Speicherung erlauben | Ermöglicht die unverschlüsselte Speicherung der Dateien *.whl und *.wvz (→ [Verschlüsselte Speicherung](../../handbuch/8_funktionen/8-13_verschluesselte_speicherung.md)). |
| Demodaten wiederherstellen | Stellt alle Demodaten aus dem Projekt wieder her. |
| Kandidat:inneneingabe fertig (alle Bereiche) | Wenn in allen Wahlbereichen die Kandidat:inneneingabe fertig ist, kann mit diesem Befehl der Status aller Bereiche gesetzt werden. |
| Auszählung fertig<br />(alle Bereiche) | Wenn in allen Wahlbereichen die Auszählung der Stimmen beendet ist, kann dieses mit einem Befehl allen Bereichen mitgeteilt werden; das ist besonders beim automatischen Einlesen wichtig. |
| Sitzverteilung starten<br />(alle Bereiche) | Alle Wahlbereiche werden mit diesem Befehl ausgewertet und die Sitzverteilung festgelegt. |
