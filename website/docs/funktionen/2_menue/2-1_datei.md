---
title: "Menü: Datei"
---

Das Datei-Menü dient zum Eröffnen, Laden und Speichern von Wahlvorgängen.

| **Befehl** | **Beschreibung** | **Taste** |
|---|---|---|
| Neue Wahl | Eröffnet einen [neuen Wahlvorgang](../../handbuch/4_vorbereitung/4-1_wahlvorgang_anlegen.md) | ![](./img/20260518103008.png) |
| Öffnen | [Laden](../../tutorium/1_laden.md) Sie einen vorhandenen Wahlvorgang | ![](./img/20260518103024.png) |
| Importiere Wahl | Erzeugt ein neuen Wahlvorgang aus einem Import (XLSX,WHL) (→ [Wahlgang anlegen)](../../handbuch/4_vorbereitung/4-1_wahlvorgang_anlegen.md) |  |
| Öffne vorherige | Öffnet den bzw. einen der vorherigen Wahlvorgänge |  |
| Arbeitsverzeichnis<br />öffnen | Öffnet das [Arbeitsverzeichnis](../../handbuch/2_installation/2-3_arbeitsverzeichnis.md) im Datei-Explorer |  |
| Speichern | Speichere Wahlvorgang unter dem bisherigen Namen | ![](./img/20260518103238.png) |
| Speichere unter... | Speichere Wahlvorgang unter einem neuen Namen |  |
| Importiere Stimmen | An mehreren Rechnern oder maschinell ausgezählte Stimmen werden eingelesen (→ [Stimmenimport](../../handbuch/6_auszaehlung_ergebnis/6-3_stimmen_importieren_exportieren.md)). |  |
| Exportiere Stimmen | Wenn die Auszählung auf mehreren Rechnern durchgeführt wird, können Zwischenergebnisse auf Datei ausgelagert und auf dem zentralen Rechner importiert werden (→ [Stimmenexport](../../handbuch/6_auszaehlung_ergebnis/6-3_stimmen_importieren_exportieren.md)). |  |
| Gremium importieren | Ein vollständiges Gremium wird aus einem anderen Wahlvorgang importiert (Kandidat:inneneingabe an verschiedenen Rechnern (→ [Verarbeitung an mehreren Arbeitsplätzen](../../handbuch/5_wahlvorschlaege/5-3_gremium_importieren.md)) |  |
| Beenden | Beendet die Bearbeitung. Wurde der Wahlvorgang nach Änderungen noch nicht gespeichert, wird dieses angemahnt. | ![](./img/20260518103157.png) |
