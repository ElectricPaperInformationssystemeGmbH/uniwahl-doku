---
title: "Menü: uniSCAN (Add-on)"
---

Dieses Menü enthält die Befehle für das Scanner-basierte Auszählen der Stimmzettel.

| **Befehl** | **Beschreibung** |
|---|---|
| Einstellungen | Hier werden der Ablauf und die Schwellwerte festgelegt. |
| Referenz-Stimmzettel vorbereiten | Referenz-Stimmzettel werden bereitgestellt und analysiert |
| Warten auf Scans im Tiff-Ordner | Er fragt, ob er auf einen Startbefehl warten soll. |
| Analysiere vorhandene Tiff-Datei | Man kann eine beliebe Datei analysieren lassen. |
| Importiere Stimmen | Einlesen der uniSCAN-Ergebnisdateien |
| Teste Stimmen | Analysiert die Ergebnisdateien, ohne die Stimmen einzulesen |
| uniSCAN - Schritt für Schritt | Liefert eine Kurzanleitung für das uniSCAN-Verfahren. |
