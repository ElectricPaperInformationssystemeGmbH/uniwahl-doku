---
title: "Menü: Ausgabe"
---

Das Ausgabe-Menü eröffnet die Funktionen zur Erstellung der Wahldokumente zur Ausgabe auf Bildschirm, Datei und Drucker.

| **Befehl** | **Beschreibung** |
|---|---|
| Terminplan | Es wird ein [Terminplan](../../handbuch/8_funktionen/8-7_terminplanung.md) in Kurzform ausgegeben. |
| Tabelle | Erstellt eine [Übersichtstabelle](../../handbuch/4_vorbereitung/4-7_uebersichtstabelle.md) über alle Wahlbereiche. |
| Wahlvorschläge | [Wahlvorschläge](../../handbuch/5_wahlvorschlaege/index.md) / Wahlbekanntmachung herausgeben |
| Stimmzettel | Erstellt [Stimmzettel](../../handbuch/5_wahlvorschlaege/5-10_stimmzettel.md) des aktuellen Wahlbereichs. |
| Auszählungs­protokoll | Erstellt [Auszählungsprotokolle](../../handbuch/5_wahlvorschlaege/5-11_auszaehlungsprotokoll.md) für den jeweiligen Wahlbereich |
| Tabelle aller Kandidat:innen | Es wird eine Datei *AlleKandidat:innen.txt* erstellt . |
| Wahlergebnis | Druckt die Bekanntgabe des [Wahlergebnisses](../../handbuch/6_auszaehlung_ergebnis/6-7_bekanntmachung.md). |
| Benachrichtigung... | Erstellt eine [Serienbriefdatei](../../handbuch/6_auszaehlung_ergebnis/6-9_benachrichtigung.md) für die gewählten bzw. nicht gewählten Personen. |
| Auswerteprotokoll | Erstellt ein [Auswerteprotokoll](../../handbuch/6_auszaehlung_ergebnis/6-5_auswerten.md) der Sitzverteilung . |
