---
title: "Menü: Wahlverzeichnis"
---

Im Menü "Wahlverzeichnis" können Verzeichnisse importiert, verarbeitet und exportiert werden, um diese z.B. im Wahlraum zu nutzen.

| **Befehl** | **Beschreibung** |
|---|---|
| Öffnen (wvz) | Der Datei-Öffnen-Dialog wird gestartet und die vorhandenen wvz-Dateien zur Auswahl angeboten. |
| Speichern (als wvz) | Wenn nur eine wvz-Datei geöffnet ist, wird diese unter demselben Namen gespeichert. Sind mehrere geöffnet, wird nach der gewünschten Datei gefragt. |
| Speichern unter ... | Nach der möglichen Auswahl des Wahlverzeichnisses wird nach dem neuen Dateinamen gefragt |
| Abgleichen | Zwei Verzeichnisse werden nach gleichen Einträgen durchsucht. |
| Durchsuchen nach Doppelten | Ein Verzeichnis wird nach doppelten Einträgen durchsucht. |
| Briefwählende übertragen | Aus dem bisherigen Wähler:innenverzeichnis werden die Briefwählenden ins neue übertragen. |
| Geänderte speichern (als wvz) | Mit dieser Funktion werden alle geänderten Wahlverzeichnisse gespeichert. |
| Schließen | Hiermit kann eine geöffnete wvz-Datei geschlossen werden. Wenn sie geändert wurde, wird eine Warnung ausgegeben. |
| Importieren | Eine Wahlverzeichnis-Tabelle, die z.B. aus einer Excel-Tabelle erstellt wurde, wird in *uniWAHL* eingelesen und im internen wvz-Format gespeichert. (→ [Wahlverzeichnis importieren](../../handbuch/4_vorbereitung/4-9_wahlverzeichnis.md)) |
| Exportieren als Excel-Tabelle | Erzeugt ein aktuelles Wahlverzeichnis als Excel-Datei zum Ausdrucken für den Gebrauch in den Wahllokalen. |
| Exportieren zu Wahlraum | Erzeugt eine Excel-Übergabedatei zum Import in uniWAHL Wahlraum (Wähler:innenregistratur bei Brief- und Präsenzwahlen) |
| Person suchen /<br />bearbeiten: | Person im Wahlverzeichnis suchen. Dafür muss mindestens ein Wahlverzeichnis geöffnet sein. |
| Briefwahldatei<br />ausgeben | Erzeugt eine Tabelle mit den Adressen aller Personen, die die Briefwahl beantragt haben (Seriendruckdatei). |
