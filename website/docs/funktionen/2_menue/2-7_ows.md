---
title: "Menü: OWS (ehemals eWAHL Add-on)"
---

Diese Funktionen unterstützen den Abstimmungsvorgang mit elektronischen Mitteln wie z.B. Online-Wahlen über das Internet.

| **Befehl** | **Beschreibung** |
|---|---|
| Einstellungen | Parameter zum Online-Wahlsystem |
| Wahlverzeichnis kodieren | Zuordnung zu Wähler:innengruppen |
| Wähler:innengruppen kontrollieren | Zur Prüfung der Gruppen |
| OWS - Schritt für Schritt | Zeigt eine Anleitung zur Einrichtung der Online-Wahl und Wähler:innengruppen mit uniWAHL OWS. |
| Nominierung erzeugen | Erzeugt eine Nominierung für uniWAHL OWS |
| Wahlverzeichnis-Prüfung | Erzeugt eine digitale Prüfung für uniWAHL OWS |
| Stimmzettel im JSON-Format erzeugen | Erzeugt eine Datei für uniWAHL OWS |
| Online-Wähler:innen in Wahlverzeichnis eintragen | Übernimmt den Wahlstatus aus dem Online-Wahlsystem. |
| Importiere Rohdaten | Die extern gewonnenen Daten importieren |
