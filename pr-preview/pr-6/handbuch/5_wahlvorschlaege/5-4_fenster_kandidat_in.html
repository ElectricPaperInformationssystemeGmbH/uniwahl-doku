Fenster: Kandidat:inneneingabe

Ein neuer Kandidat wird hinzugefügt durch Betätigen der Taste:

im Dialog des Wahlbereichs/der Gruppe bzw. der Liste, zu der er gehören soll.

Die Kandidat:innen-Daten können (auch später) bearbeitet werden durch:

„Bearbeiten F3“ im Fenster des Wahlbereichs bzw. der Liste, zu der er gehört.

oder

durch Doppelklick auf den Namen in der Kandidat:innenliste des Wahlbereich- bzw. Liste-Fensters

oder

durch Doppelklick im Navigationsfenster

Abb. : Dialogfenster zur Eingabe der Personendaten und weiterer Angaben mit Datenbankabfrage

Linke Seite: Personendaten​

  • Enthält die Personendaten des Kandidat:innen.
  • Diese Angaben werden benötigt, wenn Sie:
    1. auf den Stimmzetteln oder den Bekanntmachungen bei den Bewerbern außer dem Namen auch deren Titel, Tätigkeitsbereich angeben müssen,
    2. oder die gewählten Gremienvertreter durch Serienbriefe benachrichti­gen wollen.
  • Die Daten können in die Textfelder manuell eingegeben oder aus dem Wahlverzeichnis eingelesen werden (siehe rechtes Feld) .
  • Die Daten können manuell korrigiert oder durch zusätzliche Angaben ergänzt werden. Nicht benötigte Angaben können entfallen.
  • Die Standardfelder wie Name und die Adressangaben werden immer geöffnet. Wenn Sie weitere Infor­ma­tionen speichern wollen, können Sie die Personendaten konfigurieren.

Feld Stimmenzahl-Informationen​

Im Feld links unten werden Informationen über das auf den Kandidat:innen bezogene Wahlergebnis gezeigt, wie viele Stimmen er bekam, ob er gewählt wurde, welchen Rang er in der Liste bekam und ob zur Bestimmung der Reihenfolge gelost wurde.

Schaltfläche Vertretung​

Sieht die Wahlordnung eine persönliche Vertretung vor, gibt es zusätzlich die Schaltfläche „Vertretung“. Ist bereits eine Vertretung eingetragen, steht deren Name auf der Schaltfläche; sonst werden Sie gefragt, ob eine Vertretung angelegt werden soll. Näheres unter Persönliche Vertretung.

Rechte Seite: Feld Wahlverzeichnis durchsuchen​

Zur Übernahme von Kandidat:innen kann das Wahlverzeichnis direkt im Kandidat:innen-Fenster durchsucht werden (kein eigener Dialog).

Wählen Sie im Bereich „Wahlverzeichnis durchsuchen“ unter „Wahlverzeichnis“ das gewünschte Wahlverzeichnis aus; ist es noch nicht geöffnet, öffnen Sie es mit der Schaltfläche („Öffnen“). Anschließend können Sie im Feld „Name / Nummer“ nach einer Person mit („Suche“) suchen. Die gefundenen Einträge werden in der Trefferliste angezeigt.

Ein Klick auf eine Person in der Trefferliste (oder Enter bzw. Leertaste) überträgt deren Daten in die Personendaten. Sichern Sie mit „OK“ bzw. („Speichern“); mit („Abbrechen“) verwerfen Sie die Änderungen.

Rückfragen beim Speichern​

  • Wurden die Personendaten einer Person aus dem Wahlverzeichnis geändert, fragt das Programm: „Sollen die Änderungen in das Wahlverzeichnis übernommen werden?“
  • Kandidiert im selben Gremium bereits eine Person mit gleichem Namen, erscheint eine Warnung. Mit „Ja“ übernehmen Sie die Person trotzdem (z. B. wenn dieselbe Person mehrfach kandidieren darf). Handelt es sich um zwei verschiedene Personen gleichen Namens, wählen Sie „Nein“ und ergänzen den Namen durch einen Zusatz.
